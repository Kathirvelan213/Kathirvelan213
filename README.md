## My Projects

Here are some of my best works:


## [Farmers Grid](https://github.com/Kathirvelan213/farmers-grid)

A platform connecting farmers directly with consumers and retailers, eliminating middlemen.

* Direct farmer–buyer communication using real-time chat (SignalR)
* Smart matchmaking for improved product discovery and fair pricing
* Web and mobile applications with secure authentication (JWT + Cookies)
* Product listing, request management, and integrated logistics planning


## [BusTripManagement](https://github.com/Kathirvelan213/BusTripManagement)

A real-time bus tracking and route management system for institutions.

* Live bus movement tracking with stop-based alerts and route selection
* Flutter mobile application with a multi-layer .NET backend (API → BAL → DAL → DB)
* Real-time communication using SignalR with route-based group switching
* KML route extraction, location simulator, and route mapping



## [VirtuLingo – Language Mastery](https://github.com/Kathirvelan213/VirtuLingo-LanguageMastery)

An immersive AR/VR-based language learning platform powered by interactive AI systems.

* AI-powered virtual characters for realistic conversational practice
* Scenario-based immersive learning for improved language fluency
* Built using C# and ShaderLab with gamified modules
* Designed for beginners and individuals with verbal communication challenges
